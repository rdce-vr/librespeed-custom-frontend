    Privacy Policy

    This speed test server is configured with telemetry enabled.

    What data we collect

    At the end of the test, the following data is collected and stored:

    • Test ID
    • Time of testing
    • Test results (download and upload speed, ping and jitter)
    • IP address, ISP information, and approximate location
    • User agent and browser locale
    • Test log (contains no personal information)

    How we use the data

    Data collected through this service is used to allow sharing of test results (sharable images) and to diagnose network issues. No personal information is disclosed to third parties.

    Data removal

    If you want your information deleted, contact the server administrator or write to: telemetry@example.com.
